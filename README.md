1. Project Overview
This project documents my practical learning activities during Week 2 of my Cybersecurity and Ethical Hacking Internship at Networkwalks.

The project covers two major cybersecurity phases:

Phase 1: Reconnaissance and Footprinting
Phase 2: Scanning and Network Discovery
2. Tools Used
Tool	Purpose
Kali Linux	Security testing environment
WHOIS	Domain registration information
WhatWeb	Website technology fingerprinting
Nslookup	DNS resolution
cURL	HTTP response header analysis
Wafw00f	Web Application Firewall detection
DNSRecon	DNS enumeration
Zenmap	Network scanning and host discovery
Nmap	Network discovery engine
Windows CMD	Local IP and network information
3. Practical Activities
Activity 1: Footprinting and Reconnaissance
Performed authorized reconnaissance of the Networkwalks domain using:

WHOIS
WhatWeb
Nslookup
cURL
Wafw00f
DNSRecon
Collected information about domain registration, web technologies, IP resolution, HTTP headers, WAF detection and DNS records.

Activity 2: Network Scanning with Zenmap
Performed network discovery on my own local LAN.

Tasks included:

Identifying the local IP address.
Identifying the network subnet.
Performing a Ping Scan using Zenmap.
Discovering active network hosts.
Identifying IP and MAC addresses.
Generating a network topology.
